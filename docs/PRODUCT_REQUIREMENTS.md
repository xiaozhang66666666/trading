# 产品需求文档（PRD）

## 1. 文档信息
- 产品：多资产实时看盘与策略模拟平台
- 版本：T1 基线
- 更新时间：2026-03-17
- 目标：交付可运行的多资产策略模拟闭环，不包含真实自动下单

## 2. 背景与问题
当前个人交易者常在多个系统间切换（行情、策略、回测、通知、日志），导致：
- 数据与策略逻辑不一致
- 信号追溯困难
- 回测到实盘模拟链路断裂

本产品目标是在统一平台内打通：选标的 -> 看盘 -> 策略配置 -> 回测 -> 模拟运行 -> 通知与复盘。

## 3. 目标与范围
### 3.1 业务目标（T1）
- 支持美股与 Crypto 两类资产统一管理
- 完成策略从配置到模拟运行的全链路
- 提供信号、持仓、成交、盈亏的可追溯记录

### 3.2 范围内
- 标的管理与数据源状态
- 实时看盘与历史数据中心
- 策略中心（模板 + JSON）
- 回测系统
- 运行实例与信号引擎
- 站内通知
- 日志与报表
- 系统设置与健康检查

### 3.3 范围外（T1）
- 真实交易下单
- 多账户资金管理
- 高频 tick 级策略执行

## 4. 用户画像
- 核心用户：有交易经验、希望快速验证策略的个人交易者
- 次级用户：半专业量化用户，能理解参数和规则配置

## 5. 关键使用流程
1. 用户搜索并加入自选（如 QQQ/TQQQ/ETH）
2. 在看盘页查看行情与市场会话状态
3. 在历史数据中心拉取并导出数据
4. 通过模板或 JSON 创建策略
5. 执行回测并评估指标
6. 创建运行实例并启动模拟
7. 接收开平仓信号通知
8. 在日志与报表页复盘收益与风险

## 6. 功能需求（T1）
- T1-01 标的管理与数据源接入
- T1-02 实时看盘页面
- T1-03 历史数据中心与下载
- T1-04 策略中心
- T1-05 回测系统
- T1-06 模拟运行中心
- T1-07 实时信号引擎
- T1-08 站内信通知
- T1-09 信号日志、持仓日志、盈亏记录
- T1-10 设置与系统控制

功能明细以 `docs/FUNCTIONAL_SPEC.md` 为准。

## 7. 非功能需求
- 可用性：关键 API 具备健康检查与状态可见性
- 可追溯性：信号、成交、盈亏链路可回放
- 一致性：回测与实时模拟共用策略解释核心
- 可部署性：提供 Docker Compose 一键部署路径
- 可扩展性：数据源与策略模板可横向扩展

## 8. 成功指标（T1）
- 功能闭环：T1-01 至 T1-10 均可端到端演示
- 稳定性：核心 API 在本地/测试环境可连续运行
- 体验：关键流程（创建策略、回测、启动模拟）可在 10 分钟内完成首轮操作

## 9. 里程碑
- M1：T1-01 ~ T1-03（数据与看盘）
- M2：T1-04 ~ T1-06（策略、回测、运行）
- M3：T1-07 ~ T1-10（信号、通知、日志、系统控制）

## 10. 验收口径
- 每个任务按 `docs/FUNCTIONAL_SPEC.md` 的验收标准执行
- 每阶段必须包含：前端构建、后端测试、关键 API 手工检查
- 可部署版本需通过 Docker Compose 基础可用性验证
