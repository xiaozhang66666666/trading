# 多资产实时看盘与策略模拟平台

## 项目目标
构建一个面向个人交易者和策略探索者的 Web 平台，统一支持美股与加密货币的实时看盘、历史数据下载、策略配置、回测、模拟运行、站内通知与盈亏记录。

## 当前开发规则
- 严格按 `docs/FUNCTIONAL_SPEC.md` 顺序推进任务。
- 每次只开发一个任务，不跨任务顺手实现。
- 首个开发任务：`T1-01 标的管理与数据源接入`。
- 默认中文文案、中文注释、中文 commit message。
- UI 风格：深色专业交易终端风格。
- 默认远端开发分支：`feat/t1-01-symbol-management`；后续 Codex 每完成一个有验收结果的小阶段，都要先本地验收，再 `commit + push` 到当前工作分支。
