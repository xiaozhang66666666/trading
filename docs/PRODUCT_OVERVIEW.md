# 多资产实时看盘与策略模拟平台

## 1. 产品名称
多资产实时看盘与策略模拟平台

## 2. 产品定位
这是一个面向个人交易者、量化策略探索者的 Web 平台，支持美股与加密货币两类资产，提供从实时看盘、历史数据下载、策略配置、回测、模拟运行、实时信号通知、盈亏记录的完整闭环。

平台首期不做真实自动交易，重点解决两个问题：
1. 用户可以在一个系统里统一看美股和 Crypto
2. 用户可以把策略从“想法”快速变成“回测结果”和“实时模拟运行”

## 3. 目标用户
### 3.1 核心用户
- 有交易经验、但不一定会写代码的用户
- 想对 ETF / Crypto 做策略验证的用户
- 需要实时接收交易信号并跟踪盈亏的用户

### 3.2 次级用户
- 有一定策略思维的半专业用户
- 习惯通过参数配置、模板策略、JSON 来描述规则的用户

## 4. 核心业务闭环
选标的 → 看实时盘面 → 下载历史数据 / 查看历史走势 → 选择策略模板或 JSON 配置策略 → 回测 → 配置模拟运行 → 接收开平仓信号 → 记录信号点位和盈亏 → 手动停止 / 复盘

## 5. 支持资产范围
### 5.1 美股
首期优先支持：
- QQQ
- TQQQ

后续可扩展到更多 ETF / 股票。

### 5.2 Crypto
首期优先支持：
- ETH

后续可扩展 BTC、SOL 等。

首期 Crypto 数据源优先接入：
- Binance

## 6. 核心能力范围
### 6.1 实时看盘
- 支持多标的切换
- 支持 K 线、涨跌幅、成交量等基础行情展示
- 支持技术指标叠加
- 支持美股盘前 / 盘后展示（若数据源支持）

### 6.2 历史数据中心
- 拉取历史 K 线
- 支持按时间范围下载
- 支持 CSV / Parquet 导出
- 展示数据更新时间、数据源状态

### 6.3 策略中心
- 提供内置模板策略
- 支持通过表单配置参数
- 支持 JSON DSL 策略描述
- 支持做多 / 做空双向规则

### 6.4 回测系统
- 可选择标的、周期、时间范围、手续费、滑点等参数
- 输出交易记录、资金曲线、收益指标
- 支持多空双向回测

### 6.5 模拟运行
- 将某个策略绑定到某个标的和周期
- 获取实时数据
- 实时生成交易信号
- 支持启动 / 暂停 / 停止

### 6.6 通知与记录
- 站内信通知开仓 / 平仓信号
- 记录信号触发点
- 记录开平仓与盈亏
- 后续扩展飞书通知

## 7. 版本规划
### 7.1 T1（首版上线）
T1 是可用的首发版本，目标是把完整闭环跑通。

T1 包含：
- 美股 + Crypto 看盘
- 真实时行情展示
- 币安接入
- 美股盘前 / 盘后支持（若数据源具备）
- 历史数据下载
- 内置策略模板
- JSON 策略配置
- 回测
- 模拟运行
- 站内信通知
- 信号记录
- 盈亏记录
- 启动 / 停止 / 暂停运行

### 7.2 T2（二期增强）
T2 重点做增强和扩展。

T2 包含：
- 飞书通知
- 参数扫描 / 策略优化
- 多策略结果对比
- 多标的组合回测
- 数据源容灾与质量监控增强
- 更丰富的报表与复盘分析

## 8. 技术栈建议
| 模块 | 建议技术 |
|---|---|
| 前端 | Next.js + React + TypeScript |
| UI | Tailwind CSS + shadcn/ui |
| K线图 | TradingView Lightweight Charts |
| 统计图表 | ECharts |
| 后端 API | FastAPI |
| 策略 / 回测 / 实时引擎 | Python |
| 数据库 | PostgreSQL |
| 缓存 / 队列 | Redis |
| 实时推送 | WebSocket / SSE |
| 部署 | Docker Compose |
| 架构 | 模块化单体，后期再拆服务 |

## 9. UI 风格
整体 UI 采用专业交易终端风格，以深色模式优先。

风格要求：
- 深灰 / 黑色背景
- 蓝色作为功能强调色
- 红跌绿涨
- 信息密度高，但结构清楚
- 适合长时间盯盘和策略复盘

页面结构建议：
- 左侧：导航栏
- 顶部：市场切换、标的搜索、全局状态
- 中间：主内容区（K 线 / 回测 / 配置）
- 右侧或底部：信号日志、持仓、通知、系统状态

## 10. 核心对象定义
- Symbol（标的）：QQQ、TQQQ、ETH 等
- Market Data（行情）：实时价、K线、成交量、会话信息
- Strategy（策略）：模板策略或 JSON 策略
- Strategy Version（策略版本）：每次保存形成一个版本
- Backtest Result（回测结果）：收益、回撤、交易明细
- Run Instance（运行实例）：策略 + 标的 + 周期 + 风控 + 通知配置
- Signal（信号）：开多、平多、开空、平空
- Position（持仓）：当前仓位与方向
- Trade Log（交易日志）：实际模拟成交记录
- Notification（通知）：站内信 / 飞书

## 11. 关键业务规则
### 11.1 信号方向
首期支持四类核心信号：
- 开多
- 平多
- 开空
- 平空

### 11.2 运行方式
首期默认按 bar close 触发策略计算，避免实时逐 tick 的复杂性。

### 11.3 美股时段
- 常规交易时段
- 盘前
- 盘后

若数据源支持，则可纳入展示和策略运行。

### 11.4 Crypto 时段
- 7x24 小时连续交易

## 12. 非功能要求
- 行情状态必须明确显示：实时 / 延迟 / 断连
- 所有信号必须可追溯
- 所有模拟开平仓必须有日志
- 所有盈亏必须可复算
- 回测与实时运行应尽量使用统一策略解释逻辑，避免结果不一致
