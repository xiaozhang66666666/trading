# 功能文档（T1 / T2）

## 执行规则
- 严格按顺序执行，不跳任务。
- 每次只交给 AI 一个任务。
- 完成后只输出：
  1. 本次实现内容
  2. 修改文件
  3. 验收步骤
  4. 遗留问题

## T1：首版功能文档

### T1-01 标的管理与数据源接入
**目标**
先解决“看什么”和“数据从哪里来”的问题。

**功能点**
- 支持标的搜索
- 支持添加 / 删除自选
- 支持区分市场类型：美股 / Crypto
- Crypto 首期接 Binance
- 美股接支持真实时的行情源
- 支持展示数据源状态
- 支持展示是否为盘前 / 正常盘 / 盘后

**验收标准**
- 能搜索到 QQQ、TQQQ、ETH
- 能加入自选列表
- 能区分美股和 Crypto
- 能显示数据状态与市场会话信息

### T1-02 实时看盘页面
**目标**
搭建统一的看盘主页面。

**功能点**
- 行情卡片：最新价、涨跌额、涨跌幅、最高、最低、成交量
- K 线图展示
- 周期切换：1m / 5m / 15m / 1h / 4h / 1d
- 技术指标叠加：
  - MA
  - EMA
  - RSI
  - MACD
  - BOLL
- 美股支持盘前 / 盘后显示（若数据源支持）
- 显示当前行情状态：实时 / 延迟 / 断开

**验收标准**
- 可在 QQQ / TQQQ / ETH 之间自由切换
- K 线可正常加载
- 指标可单独开关
- 页面布局符合交易终端风格
- 盘前 / 盘后数据有明确标识

### T1-03 历史数据中心与下载
**目标**
支持数据查看、拉取、缓存、下载。

**功能点**
- 按标的、周期、时间范围拉取历史数据
- 支持 CSV 下载
- 支持 Parquet 下载
- 展示数据更新时间
- 展示数据来源
- 数据缺失检测与提示
- 支持手动刷新数据

**验收标准**
- 用户可下载 QQQ / TQQQ / ETH 的历史数据
- 下载文件结构清晰可复用
- 数据更新时间可见
- 数据异常时有提示

### T1-04 策略中心
**目标**
让不会写代码的用户也能配置策略。

**功能点**
1）内置模板策略
首期至少提供：
- MA 均线交叉
- RSI 超买超卖
- MACD 趋势策略
- 布林带突破 / 回归
- 区间突破策略

2）参数化配置
- 周期
- 开仓条件
- 平仓条件
- 止盈
- 止损
- 仓位参数
- 是否允许做多 / 做空
- 是否启用盘前 / 盘后会话

3）JSON DSL
支持通过 JSON 描述：
- 策略基本信息
- 指标定义
- 条件组合（AND / OR）
- 开多 / 平多规则
- 开空 / 平空规则
- 止盈 / 止损
- 冷却时间
- 通知配置

4）策略管理
- 新建
- 保存
- 编辑
- 复制
- 删除
- 版本管理

**验收标准**
- 不写代码也能创建一条策略
- JSON 非法时有明确报错
- 模板策略和 JSON 策略都能保存
- 策略支持多空双向

### T1-05 回测系统
**目标**
把策略跑起来，并输出可读结果。

**功能点**
- 选择标的
- 选择周期
- 选择回测起止时间
- 配置初始资金
- 配置手续费
- 配置滑点
- 配置做多 / 做空方向
- 配置是否纳入盘前 / 盘后
- 输出：
  - 交易记录
  - 收益曲线
  - 总收益
  - 年化收益
  - 最大回撤
  - 胜率
  - 交易次数
  - 盈亏比
  - Profit Factor

**验收标准**
- 同一策略可在 QQQ / TQQQ / ETH 上回测
- 能输出逐笔交易
- 能看到资金曲线
- 多空策略都能正确回测

### T1-06 模拟运行中心
**目标**
将回测通过的策略投入实时模拟。

**功能点**
- 创建运行实例
- 绑定策略版本
- 绑定标的
- 绑定周期
- 配置成本参数
- 配置风险参数
- 配置通知方式
- 支持启动 / 暂停 / 停止
- 支持运行状态展示：
  - 待运行
  - 运行中
  - 暂停
  - 已停止
  - 异常

**验收标准**
- 可创建“ETH 15m + 策略A”这类运行实例
- 运行实例可编辑、复制、删除
- 停止后不再产生新信号

### T1-07 实时信号引擎
**目标**
在实时数据到来后自动计算并产出信号。

**功能点**
- 监听实时行情
- 按 bar close 触发策略计算
- 信号去重
- 仓位状态机
- 支持信号类型：
  - 开多
  - 平多
  - 开空
  - 平空
- 记录信号触发时间
- 记录信号触发价格
- 记录触发时的策略原因快照

**验收标准**
- 同一根 K 线不会重复推送相同信号
- 平多 / 平空后持仓状态正确更新
- 信号触发后会落库保存

### T1-08 站内信通知
**目标**
确保用户在平台内可收到实时信号。

**功能点**
- 站内消息中心
- 未读 / 已读状态
- 信号通知内容包含：
  - 策略名
  - 标的
  - 周期
  - 信号方向
  - 时间
  - 价格
  - 原因摘要
- 系统异常通知
- 数据源断连通知

**验收标准**
- 信号产生后，站内信可见
- 通知内容完整
- 不重复刷屏
- 未读状态正确

### T1-09 信号日志、持仓日志、盈亏记录
**目标**
把整个模拟过程完整记录下来，方便复盘。

**功能点**
- 信号日志
- 持仓变化日志
- 模拟成交记录
- 已实现盈亏
- 未实现盈亏
- 开平仓原因快照
- 导出日志

**验收标准**
- 每一笔开仓、平仓都能追溯
- 每条信号都有时间与价格
- 盈亏结果能累计计算
- 日志可导出

### T1-10 设置与系统控制
**目标**
补齐系统运行控制能力。

**功能点**
- 数据源配置
- 默认手续费 / 滑点配置
- 时区配置
- 市场时段配置
- 运行实例启动 / 停止
- 异常状态展示
- 系统健康检查

**验收标准**
- 设置可保存
- 运行状态可控
- 系统异常有提示
- 健康检查可查看

## T2：二期功能文档

### T2-01 飞书通知
**目标**
在站内信基础上增加外部通知能力。

**功能点**
- 飞书 webhook 配置
- 飞书消息模板
- 开平仓通知推送
- 系统异常推送
- 通知开关与节流

**验收标准**
- 信号可同步推送到飞书
- 消息内容与站内信一致
- 不重复发送

### T2-02 数据质量与多数据源增强
**目标**
提升实时数据可靠性。

**功能点**
- 美股多数据源预留
- 数据源切换机制
- 断连重试
- K 线补齐
- 数据质量检测
- 盘前 / 盘后数据完整性校验

**验收标准**
- 数据断连时可提示并恢复
- 数据缺失可检测
- 美股不同交易时段显示更稳定

### T2-03 策略参数扫描与结果对比
**目标**
帮助用户快速找到更适合的参数。

**功能点**
- 参数范围配置
- 网格扫描
- 回测结果对比
- 多版本策略对比
- 策略筛选与排序

**验收标准**
- 可批量跑多个参数组合
- 可比较收益、回撤、胜率
- 对比结果清晰

### T2-04 多标的 / 组合回测
**目标**
支持不止单标的回测。

**功能点**
- 多标的批量回测
- 组合收益统计
- 多标的结果对比
- 组合回撤分析

**验收标准**
- 可同时回测多个标的
- 可生成组合级结果

### T2-05 报表与复盘中心
**目标**
把运行结果沉淀成报表。

**功能点**
- 日报 / 周报
- 信号统计
- 盈亏统计
- 持仓变化统计
- 导出复盘报告

**验收标准**
- 能自动生成基础复盘报表
- 能按时间范围查看绩效

### T2-06 策略运行增强
**目标**
让模拟运行更像真实交易管理。

**功能点**
- 反手逻辑优化
- 多实例运行管理
- 实例分组
- 统一暂停 / 启动
- 高级风控参数
- 更细的信号过滤规则

**验收标准**
- 多个运行实例可同时管理
- 高级风控生效
- 运行控制更完整
